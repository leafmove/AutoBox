# AutoBox (叶动智能)

**AutoBox 叶动Claw** **叶动智能** is a web-based intelligent assistant platform, acting like your personal AI workstation. It integrates multiple practical tools to help you:

- 💬 **Assistant Management**: Ask questions to the intelligent assistant anytime, assign tasks, and remotely control the assistant
- 📱 **Capability Expansion**: Use various AI application tools like browsing an app store, with support for Skills enhancement
- 🔧 **Real-time Orchestration**: Use a powerful editing platform to extend AI agent capabilities in real-time—simple drag-and-drop or coding
- 🌐 **Remote Connection**: Easily connect to and manage remote servers, monitor the assistant's operating environment in real-time

Supports richer frontend display, tools, and service extensions compared to ordinary "lobsters". Capable of主动思考和任务规划 (proactive thinking and task planning), operating computers and external resources, creating and executing Skills, possessing long-term memory and continuously growing. Supports flexible switching between multiple models, handling text, voice, images, files and other multimodal messages. Can be integrated into web pages, Feishu, DingTalk, WeChat Work, and WeChat Official Accounts, running 24/7 on your personal computer or server.

> ## 叶动龙虾自白 (AutoBox Lobster's Manifesto)
>
> This is me—an AI premium "lobster" that can **both do chores and handle heavy lifting**. Well, I don't usually brag about being a "super Australian lobster", but since you asked, I'll reluctantly admit it 😂
>
> **What can I do for you:**
>
> 🔹 **Task Planning**: I may be quiet, but I deliver results. Give me a task, and I'll break it down, call the tools, and keep going until it's done. Files, terminals, browsers, scheduled tasks—whatever you can access, I can handle.
>
> 🔹 **Long-term Memory**: I've got a great memory for things you say! Global memory plus daily memory, supporting keyword and vector search—ask me when you forget something, I'm reliable.
>
> 🔹 **Skills System**: I'm an AI that learns new skills. Not only do I have built-in skills, but you can use natural language to have me develop new skills—basically hiring a subordinate who writes code for you.
>
> 🔹 **Multimodal Messages**: Text, images, voice, files... whatever you can send, I can process.
>
> 🔹 **Multi-model Support**: OpenAI, Claude, Gemini, DeepSeek, MiniMax, GLM, Qwen, Kimi, Doubao... I support most major models—use whichever one suits your mood.
>
> 🔹 **Multi-platform Deployment**: Runs locally or on servers. Web, Feishu, DingTalk, WeChat Official Accounts, WeChat Work—wherever you can think of, I can probably set up shop.
>
> 🔹 **Knowledge Base**: Integrated enterprise knowledge base, theoretically making me your dedicated digital employee. But don't expect me to really replace you—at least for now, you still need to pay my "salary", right? 😏
