# 叶动智能 (AutoBox)
AutoBox（叶动智能）是一个专注于科研教育的 AI 驾驶舱，采用模块化架构设计，集成了智能体技能、连接器、本地知识库、自我进化系统、微信/飞书等外联渠道。可以帮助你直接掌控AI，操作AI智能体完成你所需要各种任务，包括不限于：垂直行业应用、编程开发、软件硬件操控、辅助思考记录、信息搜索、数据处理、图文视频生成等等，一切操作电脑的任务都可以通过驾驶舱来规划、执行、呈现

- 💬 **助手管理**：随时向智能助手提问，布置执行任务，远程遥控助手
- 📱 **能力拓展**：像逛应用商店一样，使用各种AI应用工具，支持Skills技能增强
- 🔧 **实时编排**：使用强大编辑平台，实时扩展AI智能体能力，简单拖拽或者编码均可
- 🌐 **远程连接**：方便地连接和管理远程服务器,实时监控助手运行环境

丰富的前端显示、实现工具和服务的扩展。能够主动思考和任务规划、操作计算机和外部资源、创造和执行Skills、拥有长期记忆并不断成长。支持灵活切换多种模型，能处理文本、语音、图片、文件等多模态消息，可接入网页、飞书、钉钉、企业微信应用、微信公众号中使用，7*24小时运行于你的个人电脑或服务器中。

## 叶动驾驶舱

- 进入驾驶舱之后就能够通过您的电脑完全掌控数字资产。注册钥匙即可进入😂

-  **任务规划**：别看我平时话少，干活可不含糊。你说个数，我就能帮你拆解任务、调用工具，一直折腾到完成为止。文件、终端、浏览器、定时任务——只要能访问的，我都能玩转。
-  **长期记忆**：全局记忆+每日记忆，支持关键词和向量检索，每天自动记忆，自动做梦进行总结，碰到疑难问题会记录并自动进化避免多次重复犯错。
-  **技能系统**：会自己学技能的AI。内置多种技能不说，还配有技能和应用商店，在此项目中不断开源深度使用的AutoBox skills，扩展自由度高，对接一切数字资产，操纵软硬件变得轻松自然。
-  **挂载应用系统**：通过AI编程实时生成应用，文字、图片、语音、文件……只要你能发出来的，都能处理，操作模式自由修改。
-  **多模型核心**：OpenAI、Claude、Gemini、DeepSeek、MiniMax、GLM、Qwen、Kimi、Doubao……主流模型接入，可以调用不同模型的不同功能，具体用哪个看你的需求。
-  **多端接入**：本地能跑，服务器也能跑。网页、飞书、钉钉、微信公众号、企业微信——总之你能想到的地方，我基本都能安家。
-  **知识库系统**：接入了企业知识库，理论上我可以成为你的专属数字员工。不过别指望我真能取代你——至少目前还得靠你发工资不是？😏
